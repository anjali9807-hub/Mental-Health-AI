# Dataset

This folder contains the datasets and preprocessing scripts used for training the AI Mental Health Companion.

## Files

- emotions_dataset.csv
- mood_history_sample.csv
- preprocess_dataset.py
- dataset_statistics.py
- Emotion_Training.ipynb
- LSTM_Training.ipynb

## Emotion Labels

- joy
- sadness
- anger
- fear
- love
- surprise

## Purpose

The emotion dataset is used for training the BERT emotion classification model.

The mood history dataset is used for training the LSTM mood trend prediction model.
