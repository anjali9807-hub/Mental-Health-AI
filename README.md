# AI-Powered Mental Health Companion

## Overview

This project is an AI-powered Mental Health Companion designed to monitor users' emotional well-being through daily conversations. The application analyzes text responses using Natural Language Processing (NLP) to detect emotions and mental health patterns.

The system uses a fine-tuned BERT model for emotion classification and an LSTM model to analyze long-term mood trends. A dashboard visualizes emotional patterns, identifies possible triggers, and provides personalized wellness suggestions.

---

## Features

- Daily AI-based mental health check-ins
- Emotion detection using BERT
- Mood trend prediction using LSTM
- Mood history dashboard
- Personalized wellness suggestions
- Crisis detection
- Secure user authentication
- MongoDB database integration
- FastAPI backend
- React frontend
